Planner lab: forecast look-back

Read only: nothing here changes anything. For every drop-in time in the last weeks (workshops, glazing, Mini Make, wheel and kids workshops), it pretends to be 14, 7 and 3 days before, predicts the final number using only what was known then (bookings so far, plus how similar past times picked up late), and compares with what actually happened. It also checks the close-or-keep call 3 days before (under 3 = close).
