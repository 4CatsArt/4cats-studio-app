Import projects from the sheet

In the PROJECTS_LIBRARY tab, select the rows you want including the header row, copy, and paste below. Recognized columns: Project Name, Medium, Image URL, Tags, Sizing, Make, Curriculum, Step-by-steps, Printouts/Instructions, Template, Marketing Photos link, Description, Alternate Names, project metafield. Projects that already exist by name only get their empty fields filled in; nothing already saved is erased. Cells that show link text (like "steps print link") copy as that text, not the URL, so those links need to be pasted in by hand.
